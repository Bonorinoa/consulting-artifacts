One demo was wrong; here are two that aren’t

The retracted version was a “range shrinker” built on the measurement fixture — the same engine as Midstream, relabelled. That is not Downstream. Downstream is the identification layer: whether the number is entitled to a causal reading, and what would overturn it.
What went wrong in my first pass: two different sources of ambiguity got merged into one demo. Midstream = ambiguity in what the measure means (the admissible menu M*). Downstream = ambiguity in what the design identifies (the estimator and its assumption). Both are partial identification — same mathematics, different object. Using the measurement fixture for both made Downstream Midstream wearing a different label.
First, the point — a demo earns its place only if it produces this sentence in under a minute
01 UPSTREAM
“I’m about to pay to build a measure nothing needs.” — allocation, not inference
02 MIDSTREAM
“Dropping the measure I dislike doesn’t tighten anything — it hides the disagreement.” — the paradox; this one works
03 DOWNSTREAM
“My number doesn’t survive the assumption it depends on — and here’s what would settle it.”
If a demo can’t produce its sentence, it is decoration. That test is also the answer to why there are demos at all: each one makes a claim you cannot evaluate in prose falsifiable without a call.
option A — recommended
Sensitivity to a violated identification assumption
Honest DiD (Rambachan–Roth). Parallel trends is not testable; how much violation would reverse the sign?
Under parallel trends the answer is a point — the M̄=0 slice. Relax it and the set fans out; the reader sees the assumption doing the work. The reduction is the breakdown value: how much violation flips the conclusion, benchmarked against pre-period violations.
option B — rhymes with Midstream
What a weak instrument does to the set
2SLS keeps a narrow interval; Anderson–Rubin inverts the test and the set can go unbounded.
Same lesson as Midstream, different object: a narrow interval is not a close answer when the design is weak. Elegant and citable — but it repeats Midstream’s punchline, so the two tiles start to blur.
Pick A. Unambiguously an identification assumption (not a statistic), the reduction line is Hahn-shaped — “collect a second pre-period / a placebo / another control” — and it doesn’t duplicate Midstream’s punchline. Also note a collision to fix on the page: Midstream’s scope line currently claims “specification & multiverse analysis”. An econometric specification surface belongs there or downstream, not both — I’d leave multiverse with Midstream and keep Downstream strictly to identification.
