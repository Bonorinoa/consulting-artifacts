## Variant: Missing-first

### Design stance
Open on the hole. Ask what they would measure. Then show that the obvious measure does not cover it.

### Key choices
- Layout: single column, one finding, three candidate measures as choices
- Typography: same academic tokens, larger claim
- Color: the failure is the accent
- Interaction: pick a candidate; the page tells you whether it covers abstention

### Trade-offs
- Strong at: punchline speed
- Weak at: hides the two tests that *passed*, so the audit looks like a takedown

### Best for
A landing hook, not the whole demo — the audit’s integrity finding is load-bearing.
