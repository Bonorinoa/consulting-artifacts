## Variant: Coverage / allocate

### Design stance
The visitor **turns measures on and off** and watches which decision-questions stay uncovered.

### Key choices
- Layout: implications as rows, measures as columns — a coverage matrix
- Typography: Fraunces + system mono, academic consulting tokens
- Color: oxblood for selected / load-bearing; muted for decoration
- Interaction: click a column to fund or defund it; the sentence at the bottom is the output

### Trade-offs
- Strong at: the 60-second sentence (“I’m about to ship without an abstention gate”)
- Weak at: does not force the visitor to freeze criteria *before* seeing numbers

### Best for
The actual Upstream demo. One screen, one action (allocate), real Silicus numbers.
