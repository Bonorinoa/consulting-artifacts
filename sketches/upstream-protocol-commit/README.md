## Variant: Protocol / commit

### Design stance
The visitor **freezes the ship-criteria before any number appears** — the audit’s own method, as an interaction.

### Key choices
- Layout: two beats on one page (commit, then reveal)
- Typography: same academic tokens
- Color: oxblood only after freeze
- Interaction: check which implications must hold to ship; Freeze; then findings unlock

### Trade-offs
- Strong at: participatory science, frozen-criteria honesty
- Weak at: two beats; a cold visitor may bounce before the matrix

### Best for
A first screen that composes into Coverage, not a standalone demo.
